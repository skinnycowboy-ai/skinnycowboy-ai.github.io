# Home lab engineering

Project Vaquero uses a compact lab to make platform architecture, installation,
automation, and failure behavior observable.

## Products exercised

- Red Hat OpenShift Container Platform
- Red Hat OpenShift Virtualization
- Red Hat OpenShift AI
- Red Hat Ansible Automation Platform

## Engineering focus

- Small-footprint cluster design
- Quiet and power-aware infrastructure choices
- Rebuildable installation and validation workflows
- Network, storage, registry, and disconnected-content paths
- Separation between lab evidence and production assurance
