# Red Hat Ansible Automation Platform

This collection treats automation as a governed platform capability rather than
an accumulation of unowned playbooks.

## Products and components in scope

- Red Hat Ansible Automation Platform
- Automation controller
- Private automation hub
- Event-Driven Ansible

## Focus areas

- Automation architecture and operating models
- Execution environments and governed content
- Event-driven response and closed-loop operations
- Platform, network, security, and application automation

## Questions for an automation-platform design

- Who owns reusable automation content, execution environments, credentials, and approvals?
- How are changes tested, promoted, observed, rolled back, and audited?
- Which event sources can trigger a workflow, and where must a human decision remain?
