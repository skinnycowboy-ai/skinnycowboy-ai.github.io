# Red Hat OpenShift Virtualization

This collection covers the decisions required to migrate, run, and operate
virtual machines on Red Hat OpenShift alongside containerized workloads.

## Products in scope

- Red Hat OpenShift Virtualization
- Red Hat OpenShift Container Platform
- Migration Toolkit for Virtualization
- Red Hat OpenShift Data Foundation

## Focus areas

- VM discovery and migration waves
- Storage, network, backup, and recovery design questions
- Operational readiness for VM and platform administrators
- Shared operational patterns for VMs and containerized applications
