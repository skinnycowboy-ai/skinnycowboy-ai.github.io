# Platforms for building, modernizing, and operating applications

An application platform should reduce repeated engineering work while keeping
ownership, security boundaries, and production promotion visible.

## Products in scope

- Red Hat OpenShift
- Red Hat Developer Hub
- Red Hat OpenShift GitOps
- Red Hat Trusted Software Supply Chain
- Migration Toolkit for Applications

## Technical focus

- Platform engineering and developer self-service
- GitOps responsibilities for platform and application teams
- Application assessment and modernization
- Runtime operations, policy, and observability
- Software delivery and supply-chain evidence

## Questions for architecture review

- Which services should the platform team provide consistently?
- Which choices and production responsibilities remain with application teams?
- How are changes promoted, approved, observed, and rolled back?
- What evidence links a source change to the running application?
