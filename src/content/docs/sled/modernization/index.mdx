# Modernization without unnecessary disruption

Modernization should separate the decision to change platforms from the decision
to rewrite an application. Different workloads can retain, rehost, replatform,
refactor, replace, or retire on different timelines.

## Evidence before migration

- Workload inventory, dependencies, owners, and service criticality
- Network, storage, backup, and recovery requirements
- Migration window and rollback conditions
- Target platform capacity and operational ownership
- Acceptance evidence for each migration wave
