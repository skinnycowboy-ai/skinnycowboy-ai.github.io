# Private and governed AI for public-sector workloads

Model choice follows the control boundary. Start by identifying what must remain
under organizational control and what evidence is required before an AI-assisted
workflow is accepted.

## Products in scope

- Red Hat OpenShift AI
- Red Hat Enterprise Linux AI
- Red Hat AI Inference Server
- Red Hat OpenShift
- Red Hat Ansible Automation Platform

## Technical focus

- Private model serving and inference
- Retrieval-augmented generation and data access
- Model evaluation and acceptance evidence
- AI workload operations, monitoring, and rollback
- Restricted and disconnected delivery
