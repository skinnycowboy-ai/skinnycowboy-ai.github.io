# Security controls that produce usable evidence

This section focuses on controls that can be observed, tested, and explained to
platform owners, security teams, application teams, and auditors.

## Products in scope

- Red Hat Advanced Cluster Security for Kubernetes
- Red Hat Advanced Cluster Management for Kubernetes
- Red Hat Ansible Automation Platform
- Red Hat Trusted Software Supply Chain
- Red Hat OpenShift and OpenShift AI
- Lightwell from IBM and Red Hat

## Technical focus

- Policy and configuration governance
- Vulnerability discovery, prioritization, and response
- Software supply-chain controls
- Human approvals and separation of duties
- Evidence capture, verification, and retention

## Lightwell open source remediation

Lightwell is a joint IBM and Red Hat commercial initiative for validated
remediation of eligible third-party open source dependencies. It addresses cases
where a normal upgrade creates compatibility, certification, release, audit, or
production risk. Customers consume signed remediation content through secured
repositories and retain their existing application testing, approval,
deployment, verification, and rollback responsibilities.
