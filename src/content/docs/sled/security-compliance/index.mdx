# Security controls that produce usable evidence

This section focuses on controls that can be observed, tested, and explained to
platform owners, security teams, application teams, and auditors.

## Products in scope

- Red Hat Advanced Cluster Security for Kubernetes
- Red Hat Advanced Cluster Management for Kubernetes
- Red Hat Ansible Automation Platform
- Red Hat Trusted Software Supply Chain
- Red Hat OpenShift and OpenShift AI

## Technical focus

- Policy and configuration governance
- Vulnerability discovery, prioritization, and response
- Software supply-chain controls
- Human approvals and separation of duties
- Evidence capture, verification, and retention

## Project Lightwell

Project Lightwell explores AI-assisted, human-approved, closed-loop vulnerability
remediation. It maps the remediation workflow to relevant platform capabilities
while keeping testing, approval, deployment, verification, and evidence visible.
It is a **field-developed buying motion** and demonstration concept, **not a Red
Hat product**. The design still requires architecture and product validation.

[Read the Project Lightwell technical note →](/field-notes/project-lightwell-closed-loop/)

## Questions for architecture review

- Which findings require action, exception, mitigation, or risk acceptance?
- Where must human approval and separation of duties remain visible?
- What evidence proves that policy, remediation, verification, and rollback ran as intended?
