# Security policy

This is a static documentation site. Do not add credentials, customer data,
Salesforce exports, private opportunity information, internal-only Red Hat
material, or environment files to the repository.

Before reporting a potential secret through an issue, use a private contact path
appropriate for the repository owner. Do not paste a credential or sensitive
customer detail into a public GitHub issue.

The site has no authentication, server-side runtime, database, lead form, or
social-network publishing integration. Adding any of those capabilities requires
a separate architecture and security review.
