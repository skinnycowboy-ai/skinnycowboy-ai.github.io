# ADR-0002: Editorial and data boundaries

- Status: Accepted for implementation
- Date: 2026-08-14
- Product-classification amendment: ADR 0005

## Context

The site supports a Red Hat SLED specialist role but is not an official Red Hat
product-documentation property, CRM, lead system, or autonomous social publisher.

## Decision

- Publish only role-based technical field notes suitable for public review.
- Name Red Hat products precisely when they are part of the technical subject.
- Verify product claims against current official documentation before release.
- Exclude Salesforce integration and all customer, contact, opportunity, pricing,
  and account-plan data.
- Keep social derivatives as human-reviewed drafts for approved systems.
- Describe Lightwell as a joint IBM and Red Hat commercial initiative and verify
  offering status against current official sources.
- State Project Vaquero evidence limits in every demonstration-derived article.

## Consequences

The repository can support public technical outreach without becoming a shadow
CRM or an unapproved marketing automation system. Content owners must perform
technical, editorial, confidentiality, and product-claim review before publication.
