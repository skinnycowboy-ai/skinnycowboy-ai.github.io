# ADR 0003: Organize SLED field content through a campaign hub

- Status: Superseded by ADR 0004
- Date: 2026-08-16

## Context

The first SLED navigation design connected technical notes to an internal field
workflow covering discovery, technical proof, evidence, and follow-up.

## Decision

Create a public campaign-hub page that organizes content around field buying
motions while excluding customer, account, pricing, opportunity, and contact
data.

## Supersession

After publication, the page was found to address the site author instead of the
SLED customer. ADR 0004 replaces the public campaign-hub model with a
customer-facing resource center. Internal field planning belongs in a separate,
access-controlled workspace.
